Proč to existuje

DPMP provozuje online.dpmp.cz, kde je vidět poloha spojů v reálném čase, ale nepublikuje žádný export v průmyslovém standardu. Bez něj se pardubická MHD neobjeví v Google Maps, Mapy.cz, Transitous ani v žádné analytice. Tahle služba ten most staví z veřejného API zmíněné aplikace.

Neoficiální zdroj. Feed nevytváří ani neschvaluje dopravní podnik. Vzniká odvozením z veřejně dostupného API jeho vlastní aplikace, takže se může kdykoli rozbít. Ideálním výsledkem je, že publikaci převezme sám DPMP.
